PROFILE README

The English profile is published from README.md in hzflora/hzflora.
Its artwork uses original typography and geometric line art with a shared palette:
ink navy, muted lavender and soft mint. Text stays stationary in both animations.

Active assets:
  assets/profile-header.gif - quiet orbital motion, 20-second loop
  assets/workflow.gif       - subtle workflow highlight, 12-second loop

Regenerate both assets with Python 3 and Pillow:
  python scripts/generate_assets.py

The images are stored in this repository; no external image service is required.
Earlier artwork is retained in assets but is not displayed in the current README.
